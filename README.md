## Descripción
TaskTrack es una aplicación web para la gestión de tareas y proyectos desarrollada bajo el patrón arquitectónico MVC (Modelo-Vista-Controlador). El sistema incluye autenticación de usuarios con encriptación, validación de formularios, operaciones CRUD completas para tareas o categorías, y filtrado dinámico de información.
